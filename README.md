# 我的 Python 学习仓库

这是我的 Python 零基础学习记录。

主教程：[廖雪峰 Python 教程](https://liaoxuefeng.com/books/python/introduction/index.html)

## 第一周任务

- [ ] 学会运行一个 `.py` 文件
- [ ] 学会 `print()` 输出
- [ ] 学会用变量保存内容
- [ ] 学会用 `input()` 接收输入
- [ ] 独立完成一个两数计算器

## 运行第一段代码

在仓库目录打开 PowerShell，然后运行：

```powershell
.\python.cmd .\week01\hello.py
```

`python.cmd` 是给这台 Windows 电脑准备的启动入口。以后重新打开终端后，如果
`python --version` 可以正常显示版本，也可以直接使用 `python` 命令。

## 学习规则

1. 教程里的代码自己敲，不复制粘贴。
2. 卡住 15 分钟后再问 Codex。
3. 让 Codex 提示错误原因，不让它直接完成整道题。
4. 每完成一个小功能就提交一次 Git。
